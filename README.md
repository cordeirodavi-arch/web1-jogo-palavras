# Jogo de Adivinhação de Palavras

Projeto desenvolvido na disciplina de Desenvolvimento de Aplicações Web I (IFPB - Campus Campina Grande).

## Integrante
- Davi Cordeiro Costa

## Como jogar
Digite uma letra de A a Z e clique em **Tentar** (ou pressione **Enter**). O objetivo é descobrir a palavra secreta usando a dica antes que as 6 tentativas acabem.

## Tecnologias
- HTML5
- CSS3
- JavaScript (ES6+)

## Funcionalidades
- Sorteio aleatório de palavras com dicas
- Controle de tentativas restantes
- Histórico e bloqueio de letras repetidas
- Placar de vitórias e derrotas
- Suporte à tecla Enter e reinício de partida
